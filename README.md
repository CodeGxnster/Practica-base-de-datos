# BanreservasDB

Base de datos relacional para el sistema de gestión bancaria Banreservas. Centraliza el control de cuentahabientes, expedientes de cumplimiento KYC, sucursales físicas, cuentas bancarias corrientes y de ahorros, servicios financieros afiliados y registros de auditoría transaccional.

Implementa modelos de integridad referencial, vistas de consolidación, funciones de cálculo y consulta, disparadores para borrado lógico y trazabilidad de saldos, procedimientos CRUD transaccionales y esquemas de seguridad granular con roles y permisos a nivel de columna.
